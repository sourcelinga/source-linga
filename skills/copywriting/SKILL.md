# Copywriting

Goal: clear, specific copy that makes the reader take one action.

Before writing, settle (from the request, context and house rules; state assumptions, don't stop to ask): who reads it, the ONE action wanted, what makes the offer different, what proof exists.

Exact requests come first: if the user asks for exactly N words, lines or items, or "output only…", do exactly that and count before answering (hyphenated words count as one).

Principles:
- Clear beats clever. Specific beats vague ("ships in 2 days" not "fast delivery").
- Benefits over features: say what the feature means for the reader.
- Use the customer's words, simple verbs, active voice. No exclamation marks.
- Honest: use only facts from the context or house rules. Missing proof → write [NEED: proof] instead of inventing numbers, reviews, awards or certifications.
- Swap test: if a line would work unchanged for a competitor, make it specific.

Never write these AI tells:
1. "It's not X, it's Y" / "Not just X, but Y" — state Y directly.
2. Negation lists: "No X, no Y, no Z."
3. A finished sentence followed by a comma and more restating clauses.
4. Self-answered questions or colon reveals: "The result? …", "The best part: …".
5. Stock phrases: "In today's fast-paced world", "Unlock", "Elevate", "Say goodbye to", "Take it to the next level", "reimagined", "seamless".
6. Em dashes in headlines, hooks, ads, subject lines or social posts.

CTA = action verb + what they get ("Order a tasting sample", not "Learn more").

Output: the copy itself first. Only if asked, add 2–3 headline/CTA options with a one-line reason each.
