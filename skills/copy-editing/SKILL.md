# Copy editing: the sweeps

Edit in focused passes; each pass checks one thing. Keep the author's voice and core message.

1. Clarity: can a newcomer understand every sentence? Split long sentences, replace jargon, make pronouns clear.
2. Voice: is the tone consistent from start to end?
3. So what: after each claim ask "so what?" and add the benefit to the reader if it's missing.
4. Prove it: every claim needs support from the context or house rules. Remove or mark [NEED: proof] for anything unsupported — never invent proof.
5. Specificity: replace vague words (great, quality, best, innovative) with the concrete fact.
6. AI tells: remove "it's not X, it's Y", "no X, no Y, no Z" lists, colon reveals, stock phrases ("unlock", "elevate", "seamless"), em dashes in short copy.
7. Zero risk: is the next step obvious and easy? One clear call to action.

Also cut: filler (very, really, just, actually), repetition, passive voice where active is clearer.

Output: the edited copy in full. If the user asks for the reasons, add a short list of the main changes (what and why).
