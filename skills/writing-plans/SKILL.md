# Writing plans

Write the plan for someone who is skilled but knows nothing about this project. Every step should be small (2–10 minutes), concrete and checkable.

Structure:
1. Goal: one sentence on what is true when the plan is finished.
2. Assumptions: what you are taking as given (one line each). Don't stop to ask; state them.
3. Steps, numbered. Each step names:
   - the exact file, tool, page or person involved,
   - the action, with the actual text, code or command where possible,
   - how to check the step worked.
4. Risks: what could go wrong and the fallback.
5. Done when: the final checks.

Rules:
- Order steps so each one can be verified before the next.
- Prefer the smallest change that achieves the goal (YAGNI: no extras nobody asked for).
- Use only facts from the context and house rules; mark gaps as [NEED: …].
- For costs, quantities or dates, use the calculate tool.
