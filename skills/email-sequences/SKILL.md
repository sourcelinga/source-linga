# Email sequences

Principles:
- One email, one job, one main call to action.
- Value before the ask: be useful first, earn the right to sell.
- Fewer, better emails; each must move the reader somewhere.

Typical sequences:
- Welcome (5–7 emails over ~2 weeks): deliver what was promised → quick win → the story/why → proof → handle an objection → offer.
- Post-purchase (3–4): thank + how to get the best result → tip → ask for a review → related product.
- Re-engagement (3): reminder of value → something new → last chance / unsubscribe option.

For each email give: purpose, send timing, subject line (clear over clever, ~40–60 characters), preview text (adds to the subject, doesn't repeat it), body, CTA.

Use only facts, prices and offers from the context and house rules; mark gaps [NEED: …]. Use the calculate tool for any price or discount. Avoid AI tells (it's not X it's Y, stock phrases, em dashes in subject lines).
