Get Source Linga

Private AI that runs on your Mac

Android

Before signing in, use this pairing code:shown on the Mac in Tools → Devices
Download the Android app
  1. Tap Download above, then open SourceLinga.apk from the notification or your Downloads.
  2. If Android asks, allow your browser to install unknown apps, then tap Install.
  3. Open Source Linga. It finds this Mac by itself — tap it and type the 6-digit code shown on the Mac.

The Android app hasn't been built on this Mac yet. Download it from github.com/sourcelinga/source-linga/releases instead.

iPhone and iPad

Before signing in, use this pairing code:shown on the Mac in Tools → Devices
  1. Open this page in Safari.
  2. Tap here to pair and type the 6-digit code shown on the Mac.
  3. Tap the Share button, then Add to Home Screen → Add. Source Linga now opens full screen like any app.

Another Mac

Before signing in, use this pairing code:shown on the Mac in Tools → Devices
Download the Mac app
  1. Open SourceLinga-mac.zip, then drag Source Linga into Applications.
  2. Open it. The first time, macOS may say it can't check the app: open System Settings → Privacy & Security, scroll down and click Open Anyway.
  3. In the app choose Settings → Connect to the AI on another Mac, pick this Mac and type the code.

The Mac app hasn't been built here yet. See github.com/sourcelinga/source-linga for instructions.
